Este workspace contiene dos repositorios independientes.

Backend:
- Carpeta: e-commerce-system-backend
- Django + Django REST Framework

Frontend:
- Carpeta: e-commerce-system-frontend
- React + Vite

El frontend posee sus propias skills especializadas dentro de
e-commerce-system-frontend/.agents/skills/.

El backend posee sus propias skills especialziadas dentro de
e-commerce-system-backend/.agents/skills/.

Antes de responder, determinar si la solicitud corresponde al backend,
al frontend o a ambos proyectos.

Si el cambio afecta únicamente al backend, trabajar solo en
e-commerce-system-backend.

Si afecta únicamente al frontend, trabajar solo en
e-commerce-system-frontend.

No mover archivos entre proyectos.
